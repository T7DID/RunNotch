# Changelog

All notable changes to RunNotch will be documented here.

## 0.2.0 - 2026-10-07

### Added

- Compact edge tab that reveals every tracked run on hover or keyboard focus.
- Launch with Windows enabled by default, with an immediate settings toggle.

### Changed

- The full notch now collapses after the pointer leaves instead of occupying the screen edge continuously.

## 0.1.0 — 2026-10-07

### Added

- Windows edge-notch interface with progress rings and contextual details.
- `runnotch` command wrapper for arbitrary long-running commands.
- Percentage, fraction, and attention-prompt detection.
- Local authenticated event transport and bounded persisted state.
- Success/failure notifications and configurable retention.
- Terminal focus attempt, folder fallback, and confirmed process-tree stop.
- Secret masking for common token and credential shapes.
- Portable and NSIS Windows packages.
- Unit tests and GitHub Actions workflows.
